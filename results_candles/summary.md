# Candle study: which daily candle (and its volume) predicts the next day - index ETFs

Returns in basis points (1bp = 0.01%). `cc1` = close(t)->close(t+1), `oc1` = open(t+1)->close(t+1),
`cc2` = close(t)->close(t+2). `t` = date-clustered t-stat of cc1 vs an average day. |t| > 2 ~ significant,
but with ~50 groups expect 2-3 such results by chance - only results that repeat in BOTH test sets count.

* train: main 2012-2019: 14 ETFs, 2,012 days, average day: next green 52.9%, cc1 +5.3bp
* test: main 2020-2026: 14 ETFs, 1,703 days, average day: next green 51.9%, cc1 +5.4bp
* test: fresh 2012-2026: 12 ETFs, 3,715 days, average day: next green 51.9%, cc1 +6.0bp
